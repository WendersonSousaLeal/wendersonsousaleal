👋 Sobre mim

Sou estudante de Desenvolvimento de Sistemas e estou construindo minha trajetória em tecnologia por meio de projetos práticos. Tenho interesse em desenvolvimento web, programação com Python, bancos de dados e soluções que tornem tarefas e experiências mais acessíveis.
- 🧩 Como aprendo: colocando a mão no código, experimentando e melhorando a cada versão.
- 🤟 Um tema que me move: tecnologia assistiva e acessibilidade digital.
- 🧠 No que quero evoluir: lógica, organização de código, experiência do usuário e fundamentos de Engenharia de Software.
- 🎯 Meu objetivo: construir uma base sólida e desenvolver aplicações que resolvam problemas reais.
Não estou aqui para fingir que já sei tudo. Estou aqui para aprender com consistência, mostrar o que construo e continuar melhorando.
